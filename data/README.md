# Benchmark Trajectory Data

- `sample_peo_traj.npz`: Compact 25-frame sample slice from PEO/LiTFSI Trajectory B (`3,820` atoms, `50` target Li+ ions, `M=20` periodic neighbors) for immediate smoke evaluation (`python evaluate.py`).
- Full MD trajectories for all three material systems (`li2s-traj.npz`, `siau-traj.npz`, and `peo-traj-{a..e}.npz`) are publicly archived at Materials Cloud: https://doi.org/10.24435/materialscloud:2019.0017/v1 (Xie et al., *Nat. Commun.* 2019).
